B3FG1DP0Dépose - repose : Disque de frein avant
DEPUIS OPR 7085
IMPERATIF : Remplacer systématiquement les plaquettes de frein lors du remplacement des disques.
1. Dépose
Débloquer les vis de roues.
Lever et caler l’avant du véhicule.
Déposer les roues avant.
Déposer :
  • Les plaquettes
  • L’étrier de frein
1.1. Disque ventilé
Figure : b3fp070c
Déposer :
  • Les vis (1)
  • Le support d’étrier
1.2. Dépose (suite)
Figure : b3fp071c
Déposer :
  • Les vis (2)
  • Le disque de frein
2. Repose
2.1. Disque ventilé
Reposer :
  • Le disque de frein
  • Les vis (2), Serrage à 1 m.daN
  • Le support d’étrier
  • Les vis (1), Serrage à 10,5 m.daN
2.2. Disque plein
Reposer :
  • Le disque de frein
  • Les vis (2), Serrage à 1 m.daN
Reposer :
  • Les plaquettes
  • L’étrier de frein
  • La roue
  • Le véhicule sur ses roues
Serrer les vis de roues .
