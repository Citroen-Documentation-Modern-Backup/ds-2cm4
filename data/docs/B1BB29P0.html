CARTER CYLINDRE ALUMINIUM
Figure : b1bp1bwd
L’étanchéité entre les chemises et le carter-cylindres est assurée par joints torique ( 1).
Nombre de classes de Ø A disponibles pour chaque chemise : 3.
Les 3 classes de chemises sont identifiables selon l’une des possibilités suivantes (en "a") :
  • 1 trait(s) de lime ou lettre A + 1 tiret(s) : classe A
  • 2 trait(s) de lime ou lettre B + 2 tiret(s) : classe B
  • 3 trait(s) de lime ou lettre C + 3 tiret(s) : classe C
IMPERATIF : Les chemises et les pistons doivent être de la même classe.
