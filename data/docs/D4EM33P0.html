ATTENTION : Le BSI, les calculateurs moteurs et les clés sont affectés à un véhicule et ne peuvent donc pas être échangés entre deux véhicules.
1. Mode après-vente sécurisé
On désigne le mode "après-vente sécurisé" lorsque l’opérateur doit renseigner le code confidentiel inscrit sur la carte client via l’outil de diagnostic.
Il est nécessaire de rentrer dans ce mode via l’outil de diagnostic pour réaliser différentes opérations :
  • Remplacement du BSI
  • Remplacement du calculateur moteur
  • Remplacement du BSI et du calculateur moteur
  • Remplacement de clé
  • Perte de clé
Pour rentrer dans le mode après-vente sécurisé il est nécessaire d’être en possession de la carte confidentielle ( 1) du client et de rentrer le code d’accès ou code confidentiel (a).

2. Remplacement du BSI
Le code d’accès du client est nécessaire pour le remplacement du BSI.
Avant le démontage du BSI défectueux, il est impératif de récupérer les valeurs des paramètres et configuration du BSI ainsi que la liste des calculateurs montés sur le véhicule.
Après avoir monté le nouveau BSI, il faut l’initialiser (apprentissage) pour pouvoir appairer le BSI et le calculateur moteur.
L’initialisation du BSI consiste à renseigner le code confidentiel inscrit sur la carte client dans la mémoire du BSI.
NOTA : L’appairage consiste à enregistrer de manière définitive les différents codes appris par le BSI et le calculateur moteur via l’outil de diagnostic.
ATTENTION : Une seule tentative d’écriture du code confidentiel dans le BSI est possible. Si le code est erroné, le BSI est alors inutilisable.
3. Apprentissage des clés
Le code d’accès client est nécessaire pour l’apprentissage des clés.
Pour mémoriser une nouvelle clé dans le BSI, il est indispensable de réapprendre toutes les clés.
Il est nécessaire d’avoir un boîtier de servitude intelligent déjà appairé pour effectuer les apprentissages des clés de contact.
4. Remplacement du calculateur moteur
Le code d’accès client est nécessaire pour le remplacement d’un calculateur moteur.
Lors du remplacement du calculateur moteur, il faut effectuer les opérations suivantes :
  • Programmer le code d’accès client dans la mémoire du calculateur moteur
  • Appairer le calculateur moteur et le boîtier de servitude intelligent
L’appairage du calculateur moteur et du BSI se réalise avec le +APC, il faut donc au moins une clé reconnue par le BSI.
